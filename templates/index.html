How it works

One source. Many destinations.

  1. Enter a PAT with Work Items: Read & write and validate access.
  2. Load and select any Epic, Feature, Requirement, Task, or other supported work-item type.
  3. Preview every planned create or update.
  4. Enable live writes, confirm, and synchronize.

The app saves source-to-destination ID mappings locally so later runs update the correct items. Destination workflow states are never changed.
